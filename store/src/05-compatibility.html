Compatibility

Any camera that can produce a picture

Four source types, one widget. If a camera serves a JPEG snapshot, an MJPEG stream, RTSP or ONVIF, the plugin can show it.

▣

HTTP snapshot

A URL that returns one JPEG per request. Polled at the rate you choose, with basic authentication when the camera asks for it.

▶

HTTP MJPEG

A multipart/x-mixed-replace stream. One upstream connection is shared by every viewer.

⇄

RTSP

Converted with ffmpeg on the Macro Deck computer, scaled down to the width you choose. Credentials are handled by ffmpeg.

◎

ONVIF

WS-Discovery finds cameras on the LAN, then WS-Security resolves the RTSP or snapshot address for the one you pick.

Works well with
Xiaomi Mi 360 via go2rtc Hikvision Dahua Reolink TP-Link Tapo Any ONVIF camera
Requires Macro Deck 3
ffmpeg only for RTSP
Camera reachable from the Macro Deck computer
